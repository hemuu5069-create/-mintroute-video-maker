# MintRoute AI

## Run in VS Code
1. Install Node.js LTS.
2. Extract this ZIP and open the folder in VS Code.
3. Open Terminal and run `npm install` then `npm run dev`.
4. Open the localhost URL printed by Vite.

## Included
Responsive dark mint/cyan studio, dashboard, video maker, scene editor, style registry, local project save/restore, browser speech preview, subtitle controls, audio upload, canvas preview and WebM export.

## Honest limitations
Projects are stored only in this browser using localStorage. The guest profile is local, not secure public authentication. Browser speech uses installed device voices, not cloud AI. Export is WebM, not MP4. Public multi-user accounts, shared database, secure admin roles and cloud AI generation require backend/API integration. Audio uploads are session-only and should be re-uploaded after refresh.
